# Яндекс Самокаты — тестовое задание на позицию верстальщика

Адаптивный лендинг сервиса аренды электросамокатов Яндекс Go, разработанный в рамках технического тестового задания при отборе на позицию верстальщика в компанию Яндекс. Проект сохранён в портфолио.

> **Важно:** это самостоятельная работа в рамках отбора на вакансию, а не официальный сайт Яндекса. Тексты, тарифы, ссылки и другие материалы отражают исходное тестовое задание и могут быть неактуальны.

## О проекте

Одностраничный сайт с информацией об аренде самокатов, тарифах, подписке, правилах безопасной езды и загрузке приложения. Основной акцент — реализация макета и адаптивная вёрстка.

## Технологии

- HTML5 — структура и семантическая разметка;
- CSS3 — оформление, Flexbox и медиазапросы;
- JavaScript — мобильное меню;
- [Swiper 8](https://swiperjs.com/) — слайдер;
- БЭМ-подход к именованию CSS-классов.

## Запуск локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/roman-werstka/yandex-scooters.git
   ```
2. Откройте папку `yandex-scooters`.
3. Запустите `index.html` в браузере (или через Live Server в VS Code).

Для работы некоторых медиаэлементов требуется интернет: в проекте используются внешние видео и ресурсы.

## Структура

```text
index.html       — разметка страницы
css/             — стили и адаптивная вёрстка
js/script.js     — мобильное меню и слайдер
img/             — изображения и графика
fonts/           — локальные шрифты
```
